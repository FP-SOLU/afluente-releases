# Afluente · by FP Solutions

Um espaço Windows para trabalhar com equipes de agentes.

## Instalar

Baixe o instalador x64 na [última versão](https://github.com/FP-SOLU/afluente-releases/releases/latest). O primeiro acesso orienta a conexão dos seus provedores e a criação do primeiro agente e chat.

## Atualizações

A partir da versão 0.4.3, o aplicativo consulta este canal ao iniciar e periodicamente. O aviso aparece no Afluente; você escolhe quando baixar e instalar. Instalações antigas sem canal precisam receber a 0.4.3 manualmente uma vez.

Este repositório contém somente distribuição e notas de versão. Código-fonte e desenvolvimento são privados. Seus dados locais, perfis e credenciais não fazem parte das releases.

## Requisitos e limites

Windows x64. Cada provedor exige sua própria conta e permissões. As capacidades dependem da conexão escolhida. O aplicativo precisa estar aberto para trabalhar.

Os hashes publicados permitem conferir integridade. A versão inicial não possui assinatura digital do fornecedor. Conta Claude real e segundo computador ainda estão em validação.

Afluente é um produto da FP Solutions. Os componentes de terceiros mantêm suas licenças e condições de uso.
