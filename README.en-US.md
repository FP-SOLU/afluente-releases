# Afluente

**People and agents working together.**  
Windows x64 · Built by **FP Solutions**

[Português (Brasil)](README.md) · [Download the latest release](https://github.com/FP-SOLU/afluente-releases/releases/latest) · [Changelog](CHANGELOG.en-US.md)

## Your team in one workspace

Work with agents in channels and direct chats. Share references and follow decisions, files, and deliverables. Assign Codex, Claude Code, or an OpenAI-compatible API to each agent, with its own instructions, skills, and tools.

Afluente includes missions, routines, a persistent queue, reviewed memory, attachments and screenshots, an observable local browser, and supervised previews. OKF is optional; local history and knowledge work independently.

## Install and get started

1. Open the [latest release](https://github.com/FP-SOLU/afluente-releases/releases/latest) and download the Afluente Windows x64 installer.
2. Complete onboarding: identity, workspace, providers, first agent, and first conversation.
3. Select the project folder, describe the outcome, and choose permissions in the composer.

No separate Node or Python installation is required to run the app. Each provider requires its own account, access, or API key. Vision, image generation, and quotas depend on the selected connection.

## Updates

The app notifies you when an update is available. Download and install when your tasks finish. From 0.6.3 onward, the updater checks the newest stable version again before installation and invalidates outdated intermediate downloads.

If an older app already downloaded an intermediate installer, close and reopen it to check the channel again. Installations predating the configured channel may require a one-time manual installation of a recent release.

## Data and integrity

Profiles and conversations are separate from the installation. This repository contains distribution files, metadata, and release notes only. Source code is private; profiles and credentials are excluded from releases. Published checksums let you verify files.

The app runs locally and must remain open, including in the system tray, to work. Installer signing and validation on the destination computer are separate checks. Review release notes before corporate adoption.

When reporting an issue to FP Solutions, include the version, expected behavior, and reproduction steps. Remove sensitive information from screenshots and logs.
